# Security policy

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private vulnerability reporting: open the affected repository's
**Security** tab and choose **Report a vulnerability**
(`https://github.com/yangflow/<repo>/security/advisories/new`).

Include what you found, how to reproduce it, the project version or commit and the relevant environment.
Do not include credentials, private host details or personal data. You will get an acknowledgement within
3 business days and a fix or a status update within 14 days. Please give that time before disclosing publicly.

## Scope

Vulnerabilities in the code, build and release artifacts of repositories owned by yangflow. Credential exposure,
unauthorized access and failures at trust boundaries are in scope.

## Supported versions

The latest release of each versioned project receives security fixes. For projects without tagged releases,
the main branch is supported.
