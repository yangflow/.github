# yangflow

Open-source desktop apps and self-hosted developer tools, built with AI coding agents. Pure Go and native UI
where possible.

## Projects

- [idset](https://github.com/yangflow/idset): the right Git and SSH identity in every folder, from a native tray
  app.
- [oriel](https://github.com/yangflow/oriel): a personal mixed-timeline reader for RSS and RSSHub.
- [hoplet](https://github.com/yangflow/hoplet): self-hosted remote control and cross-machine handoff for
  coding-agent sessions.
